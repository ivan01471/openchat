## 3. DEPLOIEMENT GRATUIT PERMANENT (sans ton PC allume)
### Option A — Render.com (recommande, 100% gratuit, HTTPS auto)
1. Cree un compte https://render.com + depose ce dossier sur GitHub :
     cd C:\Users\jacob\projects\openchat
     gh repo create openchat --public --source=. --push   (ou via le site GitHub)
2. Render > New+ > Web Service > connecte le repo openchat :
   Build Command : (vide) | Start Command : node server.js | Plan : Free
   Le fichier render.yaml fait deja tout (health check /healthz).
3. URL finale : https://openchat.onrender.com (gratis, HTTPS + WSS).
### Option B — Railway.app : New Project > Deploy from GitHub > Start: node server.js
### Option C — Fly.io : fly launch --region cdg ; fly deploy (fly.toml + Dockerfile fournis)
### Option D — Koyeb.com : Service > GitHub > Run: node server.js, Port 3000

## 4. DEPLOIEMENT AUTOMATIQUE (CI/CD, zero clic)
- GitHub Actions fourni : .github/workflows/deploy.yml
  A chaque `git push` sur master : syntax-check + 23 tests + (si secrets
  RENDER_DEPLOY_HOOK / FLY_API_TOKEN renseignes) redeploiement auto.
- Secrets a ajouter sur GitHub > Settings > Secrets :
  RENDER_DEPLOY_HOOK = URL du Deploy Hook Render (Service > Settings)
  FLY_API_TOKEN = `fly auth token`
- Sans secrets, le workflow valide au moins que rien n'est casse.

## 7. DEPANNAGE EXPRESS
- "Impossible de se reconnecter" : F5,Vide le cache, verifie /healthz ; le bug est
  corrige mais un F5 force toujours un socket neuf.
- Port 3000 occupe : netstat -ano | findstr :3000 puis Stop-Process -Id <pid>
- Tunnel Localtunnel = page de rappel : prefere cloudflared (start-public.bat).
- WSS casse derriere un proxy : le serveur lit l'IP du socket direct ; derriere
  Render/Railway ajoute `app.set('trust proxy')` equiv. (ici: utiliser l'en-tete
  X-Forwarded-For si tu ajoutes un reverse-proxy).
